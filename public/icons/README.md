# สร้าง PWA Icons Guide

ใช้เครื่องมือออนไลน์สร้าง icons ทุกขนาดจากโลโก้ของคุณ:

## 🔧 เครื่องมือแนะนำ:
- https://www.pwabuilder.com/imageGenerator
- https://realfavicongenerator.net/

## 📁 วางไฟล์ที่:
`public/icons/` (สร้างโฟลเดอร์ icons ใน public/)

## ✅ Checklist:
1. [ ] เตรียมโลโก้ความละเอียดสูง (อย่างน้อย 512x512px)
2. [ ] อัปโหลดไปที่ PWA Builder Image Generator
3. [ ] ดาวน์โหลด icons ทั้งหมด
4. [ ] วางใน `public/icons/`
5. [ ] ทดสอบ PWA ใน Chrome DevTools > Application > Manifest
